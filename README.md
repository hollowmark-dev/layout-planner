# 什器レイアウト検討

PDFの図面を背景に、机や書庫といった什器を**実寸（mm）で並べて検討する**ためのWebアプリです。ブラウザだけで動きます。インストールもCADのライセンスも要りません。

**👉 [アプリを開く](https://hollowmark-dev.github.io/layout-planner/)**

はじめての方は、画面の「サンプル図面で試す」から触ってみてください。

---

## 読み込んだ図面は外に出ません

PDFの読み込み・表示・書き出しは、**すべてブラウザの中だけ**で処理しています。図面も配置データもサーバーへ送信しません（送信する先がそもそもありません。GitHub Pagesは静的ファイルを配るだけです）。

社外秘の図面を扱う場合も、この点は仕様として保証されます。気になる場合は、ブラウザの開発者ツール（F12）のネットワークタブを開いたまま操作してみてください。外部への通信が出ないことが確認できます。

---

## 使い方

### 1. 図面を読み込む

「PDFを開く」から図面PDFを選びます。複数ページのPDFは、どのページを使うか聞かれます。

### 2. 縮尺を決める（ここが肝心）

読み込むと自動で「縮尺の較正」が開きます。2通りあります。

- **図面上の2点を指定する（おすすめ）** — 通り芯間隔など、長さが分かっている箇所を2点クリックし、その実寸（例：6,000mm）を入力します。印刷や縮小の影響を受けないので確実です。
  クリックの精度がそのまま縮尺の精度になります。**ホイールで拡大してから、なるべく離れた2点**を取ってください。
- **縮尺（1:100など）から決める** — PDFの用紙サイズと縮尺から計算します。原寸で出力されたPDFなら合います。

縮尺が決まるまで什器は置けません（縮尺不明のまま並べると、あとで全部やり直しになるためです）。

### 3. 什器を並べる

左のパレットから図面へ**ドラッグ＆ドロップ**。クリックしてから図面をクリックでも置けます。

- 移動はドラッグ、回転は選択したときに出るハンドル（15度きざみ、Shiftで自由）
- 隣の什器の辺やグリッドに**吸着**します（上部のチェックで切替）
- 複数選ぶと、右のパネルから「面をそろえる」「等間隔にならべる」「隙間をそろえる」が使えます

### 4. 確認する

- **通路チェック** — 什器同士の隙間を全組み合わせで測り、基準（既定800mm）を下回る箇所を赤で示します
- **計測** — 2点間の距離をその場で測ります
- **寸法線・文字** — 図面に寸法や注記を書き込めます
- **A案／B案** — 「＋複製」で案を増やし、タブで切り替えます。「他案を重ねて表示」で違いを重ねて見られます

### 5. 出す

| 書き出し | 用途 |
|---|---|
| **印刷用PDF** | 用紙（A3/A4）と縮尺（1:50/1:100…）を指定して出力。図枠に縮尺・スケールバー・日付が入るので、そのまま印刷・配布できます |
| **PNG画像** | ExcelやPowerPoint、メールに貼る用 |
| **什器数量表（CSV）** | 品名・寸法・数量・専有面積を集計。見積の下敷きに使えます（Excelで開いても文字化けしません） |
| **プロジェクト保存** | あとで再編集するため。「図面込み」で保存すればファイル1つで開き直せます |

出したPDFは縮尺どおりです。1:100で出せば、実寸1,400mmの机は紙の上でちょうど14mmになります。

## 自社什器の登録

パレット下の「＋自社什器を登録」で、よく使う什器の寸法（W/D/H・形・色）を登録できます。登録した什器は「マイ什器」としてパレットの先頭に並びます。

登録内容はその端末のブラウザに保存されます。**「書き出し」でJSONにして同僚に配れます**（受け取った側は「読み込み」でパレットに追加）。

## ショートカット

| キー | はたらき |
|---|---|
| `V` / `M` / `D` / `T` | 選択／計測／寸法線／文字 |
| `R`（`Shift+R`） | 90度回転（逆回り） |
| 方向キー | グリッド1目盛ずつ移動（`Shift`で100mm） |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す／やり直し |
| `Ctrl+C` / `Ctrl+V` / `Ctrl+D` | コピー／貼り付け／複製 |
| `Ctrl+A` / `Delete` | すべて選択／削除 |
| `Ctrl+S` | 保存 |
| `F` | 全体表示 |
| `Esc` | 中止・選択解除 |
| ホイール／`Space`＋ドラッグ | 拡大縮小／画面の移動 |

## できないこと（把握している制限）

- **平面図のみ**です。立面・断面は扱いません。
- 図面PDFは**画像として**背景に敷きます。PDF内の線を認識して壁にスナップする、といったことはしません。
- 印刷用PDFの図面部分は画像です（文字選択はできません）。日本語フォントを同梱せずに済ませるための割り切りです。
- 自動保存（前回作業の復元）には**図面画像は含みません**。復元後に同じPDFを開き直してください。同じ大きさの図面なら縮尺の設定は引き継がれます。
- 什器の3D表示や干渉チェック（高さ方向）はしません。高さは数量表に出るだけです。

## 開発

ビルド不要の静的サイトです。`docs/` 以下を編集して push すれば、そのまま GitHub Pages に反映されます。

```bash
python -m http.server 8031 --directory docs
```

サンプル図面PDFを作り直すとき:

```bash
node tools/make_sample_pdf.js
```

### 構成

```
docs/
  index.html                画面の骨格
  css/style.css
  data/furniture.json       什器テンプレートの定義（ここを増やせばパレットに出ます）
  sample/sample-plan.pdf    サンプル図面（A3・1:50・通り芯6,000ピッチ）
  vendor/                   同梱ライブラリ（CDNは使いません）
  js/
    state.js                状態・変更通知・Undo/Redo
    geom.js                 幾何計算（回転矩形の距離など）
    pdfload.js              PDFの読み込みと画像化
    calibrate.js            縮尺の較正
    actions.js              削除・複製・整列などの操作
    canvas/                 stage（座標系）／items（什器）／snap（吸着）／annot（寸法・文字）
    check/aisle.js          通路幅チェック
    ui/                     palette／inspector／layers／dom
    io/                     project（保存・読込）／export（PDF・PNG・CSV）
tools/make_sample_pdf.js    サンプル図面の生成
```

座標は**すべて実寸mm**で持ち、表示のときだけ画面倍率を掛けています。什器の `x,y` は中心位置、`rot` は度です。

### ライブラリを同梱している理由

会社のネットワークがCDN（cdnjs や jsDelivr）を遮断していると、CDN参照のアプリは動きません。このアプリは `docs/vendor/` に実ファイルを置き、すべて同一オリジンから読み込みます。**GitHub Pages が開けるなら必ず動く**という状態にしてあります。

| ライブラリ | 用途 | ライセンス |
|---|---|---|
| [pdf.js](https://mozilla.github.io/pdf.js/) | PDFの読み込み・描画 | Apache-2.0 |
| [Konva](https://konvajs.org/) | キャンバス上の図形操作 | MIT |
| [jsPDF](https://github.com/parallax/jsPDF) | PDFの書き出し | MIT |

ライセンス全文は `docs/vendor/LICENSES/` にあります。
